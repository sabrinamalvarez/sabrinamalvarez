## 🚀 Current Projects

**[CarbonCart:](https://github.com/AFXNA/carboncart)**
An app that shows the real environmental impact of product choices, beyond a single CO2 number. Includes a product scanner/search, impact visualization, and alternative-product comparisons. Built with a React/Vite front end and a Python/FastAPI backend using the Gemini API for structured data extraction, paired with a separate deterministic calculator so every number traces back to a source.

**Histopathological Image Classification:**
Built and compared three models on Google Colab with a partner to evaluate self-supervised vs. supervised learning for detecting colorectal cancer, using ResNet18, SimCLR, and DINO. Found that self-supervised methods, specifically DINO, were more cost-efficient, reaching 95.85% accuracy.

**Caro's Tutoring Website** *(planning stage):*
Designing a new website for Caro's Tutoring, hosted primarily on AWS, with billing handled outside AWS. Currently in the planning phase.
